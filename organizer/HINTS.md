# Hints

시간차 공개 또는 점수 차감용입니다.

1. **-30점:** 브라우저가 불러오는 JavaScript 끝부분과 source map을 확인하세요.
2. **-60점:** 라우터가 보는 canonical path와 bootstrap 코드가 보는 raw request-target은 동일하지 않습니다. `%2e%2e`가 유용합니다.
3. **-100점:** POSIX shell은 큰따옴표 안에서도 `$(...)`를 실행합니다. 공백 없이 환경변수를 분리하는 방법을 생각하세요.
4. **-140점:** 명령 출력은 bootstrap trace에 섞입니다. status 응답이 주는 diagnostic 경로를 다시 읽으세요.
